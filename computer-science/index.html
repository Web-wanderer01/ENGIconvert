HOW IT WORKS

Conversion steps

- Decimal → Binary: repeated division by 2. Record remainders, read bottom to top.
- Binary → Decimal: positional weights, multiply each bit by 2^position and sum.
- Between other bases: convert input to decimal (if not decimal), then from decimal to target base using repeated division.
